\chapter*{Abstract}
\addstarredchapter{Abstract}

\initial{T}he industrialisation of artificial intelligence models represents a major challenge today for organisations wishing to deploy high-performance, reliable, and sustainable solutions in production, where scaling up often faces the hurdles of increasing data volume and the complexity of automation. This thesis focuses on the design and implementation of a Cloud-based MLOps architecture dedicated to scaling up a computer vision model applied to crop anomaly detection on agricultural fields. The proposed solution relies on Amazon Web Services (AWS) and implements a strict physical decoupling between massive data engineering on one side, and the MLOps platform on the other. The processing pipeline distributes ingestion, cleaning, and dimensionality reduction through Principal Component Analysis (PCA) using an ephemeral Amazon EMR cluster under Apache Spark (PySpark), while the deep learning model life cycle is fully orchestrated via the Amazon SageMaker platform, including SageMaker Studio, the Model Registry for governance, and the deployment of a point of termination (Endpoint) for real-time inference. The isolated network infrastructure under Amazon VPC as well as AWS IAM access and role management are fully provisioned as code via Terraform and automatically deployed using GitHub Actions continuous integration and continuous delivery pipelines. The experiments conducted confirm the technical and financial viability of this architecture, demonstrating a complete elimination of local memory saturation bottlenecks, an average inference latency of 45~ms on the endpoint, and a rigorous budget management (FinOps) relying on the use of EC2 Spot instances and temporary resources, for a total monthly cost measured at 117.95~\$, thus laying down robust and highly secure foundations for the sustainable exploitation of artificial intelligence.
